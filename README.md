# makefun-tiny-chess

Entry for make.fun bounty `tiny-chess-01`: a chess engine in 4,096 bytes of Python.

[![make.fun · tiny-chess-01](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun/bounty/tiny-chess-01)
[![rank](https://make.fun/badge/tiny-chess-01/rajarmdn/makefun-tiny-chess/rank.svg)](https://make.fun/bounty/tiny-chess-01/leaderboard)
[![reward](https://make.fun/badge/tiny-chess-01/rajarmdn/makefun-tiny-chess/reward.svg)](https://make.fun/bounty/tiny-chess-01)

`main.py` (packed) plays UCI moves against the bounty's env: alpha-beta search
with piece-square tables and a capture quiescence search, fixed node budget,
deterministic. MIT licensed.
